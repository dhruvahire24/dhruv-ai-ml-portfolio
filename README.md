# Dhruv Ahire — AI/ML Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — all editable content and structure
- `style.css` — design, responsive layout and animations
- `script.js` — scroll reveal and small interactions

## Quick edit
Open `index.html` and change:
- LinkedIn URL
- Email address
- Project links
- Project descriptions
- Current learning section
- Any personal copy

## Run locally
Just open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Upload the folder to GitHub and enable GitHub Pages, or drag the folder into Netlify/Vercel.
